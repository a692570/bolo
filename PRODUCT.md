# Bolo product context
Bolo is a native macOS dictation app that types transcribed speech into the active app.
The configured dictation key starts recording while held; releasing it sends speech for transcription.
The dashboard shows actual usage counters, recent saved dictations, full history and dictation settings.
Settings include the dictation key, microphone, cleanup mode, permission setup and learned words.
Local DMG distribution to the user and friends is the current release scope.
The user wants a polished Mac utility with a recognizable Bolo identity and clear permission guidance.

Platform: macOS, AppKit/PyObjC dashboard helper with a Rust runtime and native launcher.

The product benchmark is the care and taste of Monologue and Willow Voice. This is a quality reference, not a request to copy their interface or claim feature parity.

Preserve the existing event contract and real-data boundaries. Preview transcripts and usage are synthetic and must stay labeled as previews outside the app. Do not add claims about time saved, latency, billing, security or privacy without evidence.

Current refinement: compact operating typography and layout within the existing warm paper, ink and clay brand. The app logo remains recognizable. User rejected the oversized serif dashboard headings and awkward composition of1.9.5.
